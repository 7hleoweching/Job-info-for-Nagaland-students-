# Future Skills Awareness Portal (Nagaland) 🚀

A mobile-responsive web portal designed to raise awareness about shifting employment trends in India and the importance of skill-based learning for the youth of Nagaland.

## 📌 Project Overview
Based on recent 2026 economic reports, there is a significant shift in the nature of jobs being created, with a rise in agricultural roles and a growing gap between higher education and quality employment. This project serves as a "Digital Wake-up Call" shared via social platforms to encourage students to focus on **practical tech skills** and **AI literacy**.

## 📱 Features
- **Mobile-First Design:** Optimized for viewing on smartphones via WhatsApp/Social Media.
- **Data-Driven:** Highlights the 72% rise in financial-related dropouts and the shift toward agricultural employment.
- **Tailwind CSS UI:** A clean, dark-themed "Glassmorphism" aesthetic.
- **Call to Action:** Encourages the transition from "Degree-seeking" to "Skill-building."

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS** (via CDN for rapid deployment)
- **Google Fonts** (Inter)

## 🚀 How to Host This
To share this on your WhatsApp status, you can host it for free:

1. **GitHub Pages:**
   - Create a new repository named `future-skills-nagaland`.
   - Upload the `index.html` file.
   - Go to **Settings > Pages** and enable hosting.
2. **Replit:**
   - Create a new HTML/CSS Repl.
   - Paste the code into `index.html` and click **Run**.
   - Copy the generated `.repl.co` URL.

## 📈 The Goal
The goal is to move the conversation in our community from "Will I get a job?" to "What can I build?" By focusing on specialized skills like **Mobile Development**, **AI Integration**, and **Regional Language Tech**, we can bridge the gap highlighted in current employment reports.
